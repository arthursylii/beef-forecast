Weekly resolution interpolates the live-cattle futures model (buildLCForecast) to weekly granularity, then applies each cut's 3-yr avg SP/LC seasonal ratio with smooth intra-month interpolation (no hard steps at month boundaries). Current observed premium/discount vs. the long-run ratio fades exponentially (half-life ≈ 14 weeks) rather than linearly. Cutout/live ratio itself mean-reverts toward the 5-yr average with a ~20-week half-life. Confidence bands incorporate both ratio CV and live-cattle forecast width.

🤖 ML ensemble + cross-check: a ridge regression trained per-cut on a rolling 36-month (≈156-week) USDA window targeting the SP/LC ratio (level-invariant), with recency weights (half-life ~11 mo). Features: CO/LC, seasonality, trend, momentum). Because 2023–25 absolute $ levels are below the current regime, climatology is level-scaled to today’s spot before any shrinkage, and a soft SP/LC ratio floor (hist ratio × LC × 0.92) prevents the path from collapsing under high live-cattle prices. Shrinkage toward this adjusted seasonal mean is mild (≥55 % residual retained). Momentum is capped (±20 %). The main path blends ratio-model and this ML path with a multi-factor weight (MAPE × directional accuracy × sample size), decayed by horizon (half-life ≈ 18 wk). Soft ceiling 50 %. Purple dashed line = pure ML path. Cuts with < 8 months of history show no ML component. Compare / Ratio / Heatmap / Backtest tabs reuse the same model.
